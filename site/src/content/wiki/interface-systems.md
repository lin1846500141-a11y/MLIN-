## 拆解方式

一个页面 = 网格 + 字体层级 + 颜色 token + 交互规则。先定规则，再画页面。

## 这个站的系统

- **Token**：所有颜色、间距写在 `:root` 变量里，组件只引用变量
- **组件**：页头、页面引言（page-intro）、卡片、页脚四种基础块拼出全部子页
- **零框架**：v2 用 Astro 纯静态输出重写，页面默认 0 JS，需要交互的地方才放一小段脚本

## 收益

v1（Next.js）全站约 859KB JS；v2 的 about 页为 0 JS，wiki 页只有一段筛选脚本。
